Set up your CORS Proxy (30 sec)

  1. Go to script.google.com → New project
  2. Delete everything and paste this code:
function doGet(e) {
  var url = e.parameter.url;
  if (!url) return ContentService.createTextOutput('Missing url param');
  var resp = UrlFetchApp.fetch(url, {muteHttpExceptions:true, followRedirects:true});
  var out = ContentService.createTextOutput(resp.getContentText());
  out.setMimeType(ContentService.MimeType.TEXT);
  return out;
}
  1. Click Deploy → New deployment
  2. Type: Web app → Execute as: Me → Who has access: Anyone
  3. Click Deploy, authorize, copy the URL
  4. Paste in Settings above ↑
